# Evidence for the paper

Numbers below refer to [the published arXiv paper](https://arxiv.org/abs/2611.30825).
For a CPU check, use the named reduction from the last column:

```bash
uv run --locked experiments/run-paper reduce-paper-results.py distractor-curves \
  --output artifacts/checks/distractor-curves.json
```

“Inspect” means the evidence is shipped but that item is not regenerated by the
offline command. [Reproduction](../REPRODUCING.md) lists the inputs needed for
GPU reruns.

## Names used in the evidence

Plans, units, and reports use run and arm names rather than paper numbering:

| Name | Meaning |
| --- | --- |
| `QA_PROTOCOL` | The frozen SQuAD/DROP/ROPES manifest and splits behind Table 1 |
| `EXACT_400`, `exact402` | The 400-question SQuAD set of Tables 2, 6 and 7, and the 402-question SQuAD/DROP/ROPES set of Table 3 |
| `READOUT_LADDER`, `readout_ladderc` | The single-document readout comparison (Table 2) and its rank-effect reader, also used as a runtime regression check |
| `COMPILER_FINETUNING`, `JOINT_FINETUNING` | Compiler-only and joint compiler-and-reader fine-tuning (Table 6) |
| `QUESTION_POSITION_TRANSPLANT` | Teacher-state transplants at the question positions (Table 3, left panel) |
| `PASSAGE_FITTING`, `a2-v1` | Answer-aware passage fitting (Table 8) and its frozen plan |
| `self_study` | Generated questions about a passage, used as fitting probes (Table 8) and as synthetic training rows (Table 9) |
| `QUESTION_CONDITIONED_WRITES`, `SINGLE_DOCUMENT_WRITES` | The mixed-bank and single-document question-conditioned writes (Table 9) |
| `DISTRACTOR_CURVES` | The matched-bank distractor curves on Gemma and Qwen (Figure 2, Tables 10 and 11); `reader_s<seed>` are its post-block reader seeds |
| `WRITE_SITE_READERS` | The write-site reader: `selection` chooses the arm on development data, `confirmation` scores it on test (Table 12) |
| `GATED_READERS` | The B-row gated readers (Tables 13 and 14) |
| `LAYER_INTERVENTIONS`, `LAYER_REPLICATION` | Native-below and silent-below layer interventions and membership probes on Gemma, then Qwen and DROP/ROPES (Figure 3, Tables 15 and 16) |
| `PREDICTED_GATES`, `predicted_*` | Schedules gated by probe-predicted per-rank gates (the Methods test of RQ2.3) |
| `RESPONSE_ONLY_ORACLE`, `ATTENUATION_SCHEDULES` | The prompt interventions of Table 4; `schedule_B<L>` keeps the bank silent below layer L |
| `SERVING_COST` | Analytical cost and measured throughput (Tables 18 and 19) |
| `selection`, `secondary` suites | The 180-document SQuAD development set and the DROP/ROPES transfer set of Table 1 |
| `earlier-run-NNN` | An earlier run recorded in the exclusion files, which list the documents it had used |

## Evidence formats

JSON files are reports or compact scoring references. The compressed bundles
contain completed evaluation units and expanded plans, including the matched
bank IDs and document order used in composition.
Experiment and archive labels use the names of the methods or analyses in the paper.

The PersonaMem-v2 bundles contain only test benchmark IDs, option labels,
predictions, and token counts for the published comparisons, plus the no-memory
token baseline. They do not contain prompts, memory text, retrieval exports,
or provider settings. The benchmark is attributed to
[`bowen-upenn/PersonaMem-v2`](https://huggingface.co/datasets/bowen-upenn/PersonaMem-v2)
(CC BY 4.0).
